# MaterialYou Polkit Agent
A direct replacement for polkit agents utilizing quickshell.

## Required dependencies
1. [Quickshell](https://git.outfoxxed.me/quickshell/quickshell) (> v0.3.x)
2. polkitd/polkit Service (this usually is preinstalled on your system, but you may need to install it)
3. A wayland environment (yes I finally thought about other Wayland managers than Hyprland) (with support for wlr-layer-shell protocol)

*Yes you niri users can use this, it's 100% supported, since it has an implementation for wlr-layer-shell*

*No it's not supported on GNOME or KDE since they don't have an implementation for wlr-layer-shell*

5. [Matugen](https://github.com/InioX/matugen) (> v4.x)

## Optional dependencies
1. Google Sans

> [!WARNING]
> Only **ONE** polkit agent can run in a session, so if you already have hyprpolkitagent/polkit-kde-agent/etc running, this will **not work!** so make sure to stop them first (for testing) or disable them permanently.

## Setting up the matugen and configurations:
1. Clone or [download]() this repository to `~/.config/quickshell/materialpolkit/*`
2. Add to your `config.toml` located at `~/.config/matugen/config.toml`:
```toml
[config]
# You can ignore this top line if you already have it there

[templates.materialpolkit]
input_path  = '~/.config/matugen/templates/materialpolkit-Colors.qml.template'
output_path = '~/.config/quickshell/materialpolkit/Colors.qml'
```
3. Create a matugen template file named `materialpolkit-Colors.qml.template` at `~/.config/matugen/templates/`:
```template
pragma Singleton

import QtQuick
import Quickshell

// GENERATED BY MATUGEN, edits here are overwritten. Edit the template instead:
// ~/.config/matugen/templates/materialpolkit-Colors.qml.template
Singleton {
    readonly property string fontFamily: "Google Sans Flex"

    readonly property color primary: "{{colors.primary.default.hex}}"
    readonly property color fgOnPrimary: "{{colors.on_primary.default.hex}}"
    readonly property color secondaryContainer: "{{colors.secondary_container.default.hex}}"
    readonly property color fgOnSecondaryContainer: "{{colors.on_secondary_container.default.hex}}"
    readonly property color error: "{{colors.error.default.hex}}"

    readonly property color fgOnSurface: "{{colors.on_surface.default.hex}}"
    readonly property color fgOnSurfaceVariant: "{{colors.on_surface_variant.default.hex}}"
    readonly property color surfaceContainer: "{{colors.surface_container.default.hex}}"
    readonly property color surfaceContainerHigh: "{{colors.surface_container_high.default.hex}}"
    readonly property color surfaceContainerHighest: "{{colors.surface_container_highest.default.hex}}"
}
```
